Why GitHub Pages shows a 404 for Python Backends

GitHub Pages hosts static HTML/CSS files only. Because this application is built with Django (Python backend + SQLite database), it requires a Python server (such as Render or PythonAnywhere) to run the dynamic server code.

Quick Local Start Instructions

Run the following commands in your terminal to start the live web application on your machine:

git clone https://github.com/santhoshkumar-techcoder/ONLINE-BOOK-STORE.git
cd ONLINE-BOOK-STORE
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver

Open http://127.0.0.1:8000 in your browser to view the application!
